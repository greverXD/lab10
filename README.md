# Аренда квартир (лабораторная работа №6, вариант 4)

Консольное приложение на C# (.NET 8) для сдачи квартир в аренду. Данные о квартирах хранятся в XML-файле и разделены по регионам.

**Клиент:** выбор региона и квартиры, поиск по ключевому слову, подбор по фильтрам (регион, цена, комнаты, площадь, мебель, животные, этаж), сортировка, расчёт стоимости аренды, сохранение квартиры в текстовый файл (папку и имя файла вводит пользователь). У каждой квартиры считаются просмотры, счётчик сохраняется в XML.

**Собственник:** добавление объявления (можно в новый регион), просмотр своих объявлений по номеру телефона, удаление.

**Отчёты:** сводка по регионам, топ квартир по просмотрам, каталог. Отчёты записываются в папку `Reports`.

## Запуск

```
cd ApartmentRental
dotnet run
```

| Коллекции объектов | `List<Apartment>`, `List<ApartmentFilter>` и др. |
| Запись коллекции в файл (LINQ to Objects) | `Services/ReportService.cs` |
| Делегаты | `Models/Delegates.cs` (`ApartmentFilter`, `ApartmentEventHandler`) |
| Данные | `Data/apartments.xml` |
